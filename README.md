# 우리집 가계부

현기·장미 부부가 둘이 같이 쓰는 가계부 · 재무설계 PWA.

- 앱: https://banhyunky.github.io/budget/
- 설치: 폰 브라우저에서 위 주소를 연 뒤 **홈 화면에 추가** (안드로이드 크롬: ⋮ → 홈 화면에 추가 / 아이폰 사파리: 공유 → 홈 화면에 추가)

## 기능

- **홈** — 이번 달 남은 여유 자금, 사용률, 곧 빠져나갈 돈(대출·카드·보험·통신 등) D-day 순, 원터치 납부완료
- **내역** — 월 이동, 현기/장미/공동 필터, 날짜별 기록, 눌러서 수정·삭제
- **고정비·설계**
  - 고정 수입(월급 등) 등록 — 매달 다시 입력할 필요 없이 자동으로 잡힘
  - 고정비(대출·카드·보험·통신·주거) 등록·수정, 캡처로 한꺼번에 불러오기
  - 예적금 계좌(이름·월 납입액·현재 잔액·만기일) 관리, 잔액이 순자산에 자동 반영
  - 고정비/변동비 비율, 저축 목표 달성률, 대출 잔액·순자산
- **나만 보기** — 기록마다 비공개로 담을 수 있어요. 상대 화면에서는 금액은 그대로 합계에 잡히고 내용만 `비공개 지출`로 가려져, 합계는 정확히 맞으면서 무엇을 샀는지는 보이지 않아요. (내 화면에서는 자물쇠 표시와 함께 전체 내용이 보임)
- **📷 캡처 사진으로 자동 입력 (거래·고정비·예적금)** — Gemini가 캡처를 읽어 검토 목록으로 보여주고, 한 번에 담아요. 시트 위쪽에서 세 가지 중 고르면 됩니다.
  - **거래 내역** — 은행·카드 내역 캡처에서 날짜·가맹점·금액·수입/지출. 행마다 체크·지출/수입·누구(현기/장미/공동)·분류·날짜·`나만 보기`를 고칩니다.
  - **고정비·카드** — 토스·은행의 대출 화면이나 카드 청구 예정 화면에서 이름·분류(대출/카드/보험/통신/주거/기타)·월 금액·납부일·대출 잔액·금리. 담으면 **재무설계의 대출 잔액**도 함께 바뀌어요. 고정비 탭의 `📷 대출·카드 청구서 캡처로 불러오기`로 바로 열 수도 있습니다.
  - **예적금** — 은행 앱의 예·적금 현황에서 상품명·종류(적금/예금)·잔액·월 납입액·만기일. 잔액 합계와 순자산에 바로 반영됩니다.
  - **중복은 알아서 표시해요.** 거래는 같은 날·같은 금액·같은 수입/지출이 이미 있으면 `이미 기록됨 · 중복 의심`과 함께 기본으로 선택이 꺼지고, 고정비·예적금은 이름이 같은 항목이 있으면 `기존 항목 업데이트`(원하면 `새로 추가`)를 고를 수 있어요.
  - 키가 없어도 `샘플 캡처 인식 체험` / `토스 대출 예시` / `예적금 예시`로 검토 화면을 먼저 볼 수 있습니다.
- **카드 알림 자동 수집** — 설정에서 수신 주소 형식을 확인하고, `카드 알림 테스트`로 `[신한카드] 승인 14,800원 스타벅스` 같은 문구가 어떻게 읽히는지 바로 볼 수 있어요. (실제 자동 수신은 Firebase 연결 후 수신 함수를 붙이면 동작)
- **설정** — Firebase 연결(둘이 실시간 공유), Gemini API 키(캡처 인식, 이 기기에만 저장), JSON 백업/복원, 샘플 데이터 초기화

## 저장 방식

- 인터넷이 없거나 연결을 해제하면 **로컬 모드**로 동작하고, 데이터는 그 폰의 브라우저(localStorage)에 저장됩니다.
- 기본은 **Firebase 자동 연결**: 앱을 처음 열면 `banhyunky-budget` 프로젝트에 바로 연결되고, 이 기기 몫의 **가계부 ID·PIN**이 자동으로 만들어집니다 (설정에서 확인·복사 가능).
- 장미님 폰처럼 다른 기기에서는 설정에 같은 **가계부 ID + PIN**을 넣으면 둘이 실시간으로 같은 가계부를 봅니다. 다른 Firebase 프로젝트를 쓰려면 설정에서 `firebaseConfig`를 바꿔 넣으면 됩니다.
- 이 저장소는 **공개 저장소**입니다. 실제 가계 데이터는 저장소에 넣지 않았고, 샘플 데이터만 코드에 들어 있습니다.
- **Gemini API 키**는 `localStorage`에만 저장됩니다. 저장소·코드·Firebase 동기화·JSON 백업 어디에도 실리지 않아요.

## 구성

빌드 단계 없는 단일 페이지 PWA입니다.

```
index.html      앱 전체 (HTML+CSS+JS)
manifest.json   PWA 매니페스트
sw.js           오프라인 캐시 서비스워커 (budget-v11)
icon-192.png    아이콘
icon-512.png    아이콘
make_icons.py   아이콘 생성 스크립트
```

화면을 고친 뒤에는 `sw.js`의 `V` 값을 올려 주세요.
