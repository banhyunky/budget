# 문자·알림 자동 수집 설치 안내

현기·장미 두 폰의 **문자(SMS)** 와 **금융 앱 알림**을 머니로그 가계부에 자동으로 넣는 방법입니다.
폰에서 일어나는 일은 이렇게 흘러갑니다.

```
현기 폰 문자/알림 ─┐
                  ├→ MacroDroid (HTTP POST) → Apps Script 웹 앱 → Firebase(가계부) → 두 폰 화면에 바로 반영
장미 폰 문자/알림 ─┘
```

준비물: 안드로이드 폰 2대, 구글 계정, MacroDroid(무료), 그리고 아래 파일 하나.

- 스크립트: [`Code.gs`](Code.gs)
- 이 안내서: `SETUP.md`

> 아이폰은 문자를 다른 앱이 읽을 수 없어서 이 방식이 안 됩니다. (안드로이드 전용)

---

## 0. 먼저 알아 둘 것

| 상황 | 가계부에 남는 것 |
|---|---|
| 카드 승인 문자 `[신한카드] 승인 14,800원 스타벅스` | 지출 14,800원 · 식비 |
| 같은 결제의 카드사 앱 알림이 3분 안에 또 옴 | **한 건만** (중복 버림) |
| 현기 → 장미 1,000원 이체 (보낸 폰) | 🔄 부부 이체 1,000원 · **집계 제외** |
| 같은 이체를 장미 폰도 받음 | 새 줄을 만들지 않음 (한 줄 유지) |
| 보낸 문자에 상대 이름이 없어도, 장미 폰에 같은 금액 입금이 10분 안에 잡힘 | 두 기록을 짝지어 🔄 부부 이체 한 줄로 정리 |
| `승인취소`, 인증번호, 광고/혜택 알림 | 기록하지 않음 |

- **부부 이체**는 수입·지출·카테고리·AI 코치 어디에도 더해지지 않습니다. 같은 돈이 두 번 잡히지 않게 하려는 것입니다.
- 금액을 못 찾은 문자는 기록하지 않고 응답에 `parse_failed` 라고만 알려 줍니다. (조용히 이상한 금액을 넣지 않으려고)

## 1. Apps Script 웹 앱 만들기 (5분)

1. 폰이나 PC 브라우저에서 **https://script.google.com** → `새 프로젝트`
2. 왼쪽 위 이름을 `머니로그 문자수집` 으로 바꿉니다.
3. 편집기에 있는 기본 코드를 **전부 지우고** [`Code.gs`](Code.gs) 내용을 그대로 붙여넣습니다.
   - 폰에서는 GitHub에서 `Code.gs` → **Raw(원시 보기)** → 길게 눌러 전체 선택 → 복사하면 됩니다.
4. 맨 위 설정에서 **비밀값 하나만** 바꿉니다.

   ```js
   var CFG = {
     SECRET: 'CHANGE_ME_moneylog_2026',   // ← 이 값을 다른 사람이 모르는 값으로 바꾸세요
     PROJECT_ID: 'banhyunky-budget',
     HOUSE_ID: 'hy-vtrxxa8dq6',
     ...
   ```

   - `SECRET` 은 20자 이상 아무 영문·숫자나 좋습니다. 예: `moneylog-7f3c9a1b-hy-2026`
   - 바꾸지 않고 기본값(`CHANGE_ME…`) 그대로 두면 **서버가 모든 요청을 거부**합니다(`secret_not_set`). 안전장치입니다.
   - `PROJECT_ID` 와 `HOUSE_ID` 는 **그대로 두세요.** 머니로그 앱 설정의 `가계부 ID` 와 같아야 합니다.
   - 바꾼 비밀값은 **4단계 MacroDroid 본문에도 똑같이** 넣습니다. 메모해 두세요.
5. 저장(Ctrl+S 또는 💾).

### 확인 1 — 문자 해석

편집기 위쪽 함수 선택에서 **`testParse`** → `실행`.
처음이면 권한 창이 뜹니다: `권한 검토` → 계정 선택 → `고급` → `(프로젝트 이름)(으)로 이동` → `허용`.
아래 **실행 기록**에 `=== 통과 14 / 실패 0 ===` 처럼 나오면 정상입니다.

### 확인 2 — 가계부 연결

함수 선택에서 **`testFirestore`** → `실행`.
`가계부 문서 확인: households/hy-vtrxxa8dq6 · 기록 8건 · 수정시각 …` 처럼 나오면 연결 성공입니다.
(읽기만 합니다. 가계부는 건드리지 않습니다.)

> `가계부 문서를 읽지 못했어요 (403)` 이 나오면 Firebase 콘솔 → Firestore → 규칙이 아래처럼 열려 있는지 확인하세요.
> 지금 머니로그 앱이 쓰는 규칙입니다.
>
> ```
> match /households/{id} { allow read, write: if true; }
> ```

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포** → **새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 아래처럼 지정합니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | 머니로그 문자수집 |
   | 다음 사용자 권한으로 실행 | **나** |
   | 액세스 권한 | **모든 사용자** |

4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/AKfy…/exec`)을 복사합니다.
5. 브라우저 주소창에 그 URL을 열어 봅니다. 아래처럼 보이면 살아 있는 것입니다.

   ```json
   {"ok":true,"name":"moneylog-webhook","version":"1.0.0","house":"hy-vtrxxa8dq6","time":"2026-11-21 12:34:56"}
   ```

> 코드를 고치면 **배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포** 를 다시 해야 실제 주소에 반영됩니다.
> (저장만 하면 예전 버전이 계속 돌아갑니다.)

---

## 3. 머니로그 앱에 주소 넣기

1. 머니로그 → 오른쪽 위 설정(⚙️)
2. **문자·알림 자동 수집** → `웹훅 주소` 칸에 복사한 URL을 붙여넣고 **주소 저장**
3. 옆의 **주소 복사** 를 누르면 MacroDroid에 붙여넣을 주소가 복사됩니다.
   (두 폰 모두 같은 주소를 씁니다. 주소는 가계부 설정에 저장돼 장미 폰에도 함께 보입니다.)

## 4. MacroDroid 설치 — 현기 폰

1. Play 스토어에서 **MacroDroid** 설치 (무료판은 매크로 5개까지 — 2개만 쓰므로 충분)
2. 앱을 열고 안내에 따라 권한을 허용합니다.
   - **알림 접근** (알림을 읽으려면 필수)
   - **SMS 권한** (문자를 읽으려면 필수)
3. 휴대폰 설정 → 앱 → MacroDroid → **배터리 → 제한 없음** 으로 바꿉니다.
   (안 하면 며칠 뒤부터 조용히 안 옵니다.)

### 매크로 ① 문자 받기

1. **+ 새 매크로** → 이름 `머니로그 문자`
2. **트리거** → `문자 메시지 수신`(SMS Received) → 발신자 `모든 번호` → 내용 `모든 내용`
3. **동작** → `연결`(Connectivity) → **`HTTP 요청`**(HTTP Request)
4. 이렇게 채웁니다.

   | 항목 | 값 |
   |---|---|
   | 방식 | **POST** |
   | URL | 3단계에서 복사한 웹훅 주소 |
   | 콘텐츠 타입 | **application/json** |
   | 본문(Body) | 아래 JSON |

   ```json
   {"secret":"여기에_1단계_비밀값","owner":"현기","source":"sms","app":"{sms_name}","title":"","text":"{sms_message}","at":"{sms_received_time}"}
   ```

   - `{sms_name}` `{sms_message}` `{sms_received_time}` 은 MacroDroid의 **매직 텍스트**입니다.
     지우지 말고 그대로 두세요. (파란 `…` 버튼에서 골라 넣어도 됩니다.)
   - 본문 칸 이름은 버전에 따라 `Body` · `요청 본문` 으로 보일 수 있습니다.
   - **표(키-값) 형식만 있는 버전**이라면: 콘텐츠 타입을 `application/x-www-form-urlencoded` 로 두고
     `secret` `owner` `source` `app` `title` `text` `at` 을 한 줄씩 키-값으로 넣어도 됩니다. (서버가 둘 다 받습니다)
5. 저장 → 매크로 목록에서 ▶ 로 한 번 실행해 봅니다. (문자 없이 실행되면 `ignored` 로 끝나고, 그게 정상입니다)

### 매크로 ② 알림 받기

1. **+ 새 매크로** → 이름 `머니로그 알림`
2. **트리거** → `알림 수신`(Notification Received) → **앱 선택**에서 아래 앱들을 고릅니다.
   - 토스, 카카오뱅크, 케이뱅크, KB국민은행(스타뱅킹), 신한 SOL, NH농협, 우리은행, 하나은행, IBK기업은행, 부산은행(BankOn)
   - 삼성카드, 현대카드, 롯데카드, 신한카드, KB국민카드, 우리카드, 하나카드
   - 삼성페이, 카카오페이, 네이버페이
   - (앱 이름은 폰에 설치된 이름 기준입니다. 없으면 그 앱은 그냥 빼세요.)
   - **카카오톡은 넣지 마세요.** 알림톡과 친구 채팅이 같은 앱에서 와서, 친구가 보낸 "1만원 보냈어" 같은 대화까지 기록될 수 있습니다. 은행·카드 앱 알림과 문자로 충분합니다.
3. 같은 트리거 화면에서 **텍스트 필터 → 포함 → `원`** 을 넣으면 광고 알림이 크게 줄어듭니다.
4. **동작** → `연결` → **HTTP 요청** → 문자 매크로와 같은 방식으로, 본문만 아래로 바꿉니다.

   ```json
   {"secret":"여기에_1단계_비밀값","owner":"현기","source":"push","app":"{not_app_name}","title":"{not_title}","text":"{notification} {not_text_big}","at":"{not_timestamp}"}
   ```

   - `{notification}` 은 알림 본문, `{not_text_big}` 는 펼쳤을 때의 긴 본문입니다. 둘을 같이 보내면 어느 쪽에 금액이 있어도 잡힙니다.
   - 제목에 보낸 사람 이름이 들어오는 앱도 있어서 `{not_title}` 도 함께 보냅니다.

### 장미 폰

같은 두 매크로를 똑같이 만듭니다. **딱 한 곳만** 다릅니다.

```json
"owner":"장미"
```

(문자 매크로·알림 매크로 **둘 다** `장미` 로)

## 5. 진짜로 되는지 확인

가장 확실한 방법은 **1,000원을 실제로 이체**해 보는 것입니다.

1. 현기 폰에서 장미 계좌로 1,000원을 보냅니다.
2. 5초 안에 머니로그 **내역**에 `🔄 부부 이체 1,000원` 한 줄이 뜨면 성공입니다.
   - 현기 폰 알림: `출금` → 현기 폰 문자/알림이 먼저 도착
   - 장미 폰 알림: `입금` → 장미 폰이 도착하면 **새 줄을 만들지 않고** 같은 이체로 정리
3. 이번 달 **지출** 금액이 1,000원 늘지 **않았는지** 확인하세요. (늘었다면 아래 문제 해결)
4. 카드로 1,000원 결제해 보면 **지출**로 한 줄 들어옵니다.

Apps Script 편집기의 **실행 기록(Executions)** 에서 방금 요청의 응답을 볼 수 있습니다.

```json
{"ok":true,"status":"added","kind":"transfer","amount":1000,"cat":"이체","memo":"현기 ↔ 장미","owner":"현기","date":"2026-11-21"}
```

`status` 뜻: `added` 새로 기록 · `duplicate` 이미 있음 · `upgraded` 중복을 이체로 정리 · `paired` 배우자 기록과 짝지음 · `ignored` 버림(취소·인증번호 등) · `parse_failed` 금액을 못 찾음

## 6. 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 들어옴 | Apps Script **배포**가 `모든 사용자` 인지, 주소가 `…/exec` 로 끝나는지. 브라우저로 주소를 열어 `{"ok":true}` 가 보이는지 |
| 실행 기록에 `bad_secret` | 1단계 `SECRET` 과 MacroDroid 본문 `secret` 이 같은지 (따옴표·공백 포함) |
| 실행 기록에 `parse_failed` | 그 문자에 `1,000원` 처럼 금액이 있는지. 없으면 정상 동작입니다 |
| 문자는 되는데 알림이 안 옴 | **알림 접근** 권한, 트리거의 앱 선택, 배터리 제한 없음 |
| 며칠 뒤부터 안 옴 | 배터리 최적화. MacroDroid를 '제한 없음'으로 |
| 기록은 되는데 화면이 안 바뀜 | 머니로그 앱이 Firebase에 연결돼 있는지(설정 상단 상태) |
| 이체가 지출로 잡힘 | 두 폰 모두 매크로를 켰는지, 문구에 `장미`/`현기` 이름이 있는지. 이름이 없으면 배우자 폰의 반대 기록(같은 금액 10분)과 짝지어 정리합니다 — 그래서 **두 폰 모두** 설정하는 게 중요합니다 |
| 카드 결제가 두 번 | 같은 결제가 3분 이상 떨어져 도착했을 수 있습니다. 내역에서 하나를 지우면 됩니다 |

## 7. 알아 둘 점

- **현재 Firestore 규칙은 공개**(`allow read, write: if true`)입니다. 그래서 웹훅이 별도 로그인 없이 가계부에 쓸 수 있습니다. 대신 주소와 비밀값을 아는 사람은 쓸 수 있으니 `SECRET` 을 충분히 길게 하고 아무에게도 알려 주지 마세요.
- 나중에 규칙을 인증 필요로 조이면 이 웹훅도 서비스 계정 키가 필요해집니다. 그때는 웹훅을 잠시 끄고(배포 → 보관) 앱만 쓰면 됩니다.
- 무료 Google 계정 기준 하루 UrlFetch 20,000회로, 하루 수십 건인 가계부에는 넉넉합니다.
- 응답 본문에는 가계부 내용을 담지 않습니다. 성공·중복·버림 여부와 금액만 돌려줍니다.
- 스크립트 사본은 이 저장소(`webhook/Code.gs`)에 있습니다. 실제 비밀값은 **Apps Script 편집기에만** 넣으세요. 저장소는 공개입니다.
